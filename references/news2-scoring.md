# NEWS2 评分表与临床响应阈值

> 本文件是本 Skill 评分与报警的**唯一依据来源**。Agent 不得凭模型记忆修改任何阈值。
> 教学用途，使用前须由小组成员对照 RCP 原文逐项核对。

## 一、评分表（SpO₂ 量表 1）

NEWS2 共 7 个评分项：6 项生理指标 + 1 项是否吸氧。每项 0～3 分，总分范围 0～20。

### 呼吸频率（次/分）

| 范围 | 得分 |
| --- | --- |
| ≤ 8 | 3 |
| 9–11 | 1 |
| 12–20 | 0 |
| 21–24 | 2 |
| ≥ 25 | 3 |

### SpO₂ 量表 1（%）

| 范围 | 得分 |
| --- | --- |
| ≤ 91 | 3 |
| 92–93 | 2 |
| 94–95 | 1 |
| ≥ 96 | 0 |

### 吸氧情况

| 状态 | 得分 |
| --- | --- |
| 吸氧 | 2 |
| 空气 | 0 |

### 收缩压（mmHg）

| 范围 | 得分 |
| --- | --- |
| ≤ 90 | 3 |
| 91–100 | 2 |
| 101–110 | 1 |
| 111–219 | 0 |
| ≥ 220 | 3 |

### 心率（次/分）

| 范围 | 得分 |
| --- | --- |
| ≤ 40 | 3 |
| 41–50 | 1 |
| 51–90 | 0 |
| 91–110 | 1 |
| 111–130 | 2 |
| ≥ 131 | 3 |

### 意识（ACVPU）

| 状态 | 得分 |
| --- | --- |
| A 清醒 | 0 |
| C 新发意识模糊 / V 对声音有反应 / P 对疼痛有反应 / U 无反应 | 3 |

只要不是 A（清醒），一律计 3 分。「C」指**新出现**的意识模糊、定向障碍，或原有状态加重。

## 二、报警级别与临床响应

| 评分情况 | 报警级别 | 最低监测频率 | 临床响应 |
| --- | --- | --- | --- |
| 总分 0 | 无报警 | 每 12 小时 | 常规监测 |
| 总分 1–4 | 低 | 每 4–6 小时 | 由注册护士评估，决定是否增加监测频率或上报 |
| 任一单项 3 分（总分 < 5） | 低–中 | 每小时 | 护士通知负责医疗团队，由医生评估是否需要升级 |
| 总分 5–6 | 中 | 每小时 | **紧急响应阈值**（key threshold for urgent response）：立即通知负责医疗团队，由具备急症患者照护能力的临床人员进行紧急床旁评估；在具备监护条件的环境中提供临床照护 |
| 总分 ≥ 7 | 高 | 持续监测 | **急救响应阈值**（emergency response threshold）：立即通知负责医疗团队（至少达专科主治级别），紧急评估是否需要重症监护团队介入；在具备高级监护能力的环境中提供临床照护 |

**5–6 与 ≥7 的区别**：两档都要求立即通知，但响应层级不同——5–6 由负责医疗团队紧急床旁评估，≥7 需考虑重症监护团队介入，并要求更高级别的监护环境。Agent 输出时须保持这一区分，不可混用措辞。

**判定顺序（命中即停）**：总分 ≥7 → 总分 5–6 → 单项 3 分 → 总分 1–4 → 总分 0。

## 三、适用范围

| 适用 | 不适用（V1 不评分，提示按医院流程处理） |
| --- | --- |
| 16 岁及以上成人 | 16 岁以下儿童（使用儿童专用评分） |
| 非妊娠、非产后患者 | 妊娠或产后患者（使用产科专用评分） |
| 普通病房住院患者 | 医嘱规定使用 SpO₂ 量表 2 或目标血氧 88%–92% 的患者 |

## 四、低血氧处理规则

SpO₂ ≤ 91% 时：提示立即检查指夹位置并复测，同时进行床旁评估。**在复测确认之前，不得把低读数当作伪差忽略**，即使患者看起来交谈自如。

## 五、核对记录

本文件的评分表与临床响应表已由小组成员对照 **RCP 官网**（rcp.ac.uk → Resources → National Early Warning Score (NEWS) 2）的 Chart 1（The NEWS scoring system）与 Chart 4（Clinical response to NEWS trigger thresholds）逐项核对。

核对结论：
- **评分表 7 项阈值：全部一致**，无需修改
- **临床响应表**：0 / 1–4 / 单项 3 分 三档一致；5–6 与 ≥7 两档的响应描述原先区分度不足，已按官方 Chart 4 补充「urgent response」与「emergency response」两级阈值命名、响应层级与监护环境要求

说明：意识项本文件写作「A 清醒 / C 新发意识模糊、V、P、U」，官方 Chart 1 写作「Alert / CVPU」，二者含义一致；本文件显式列出 new confusion，与官方对该项的特别强调相符，故保留现有写法。
